Context API

Context provides a way to pass data through the component tree without having to pass props down manually at every level.

What I Learned

Global state without prop drilling

01

No Prop Drilling

Avoids passing props through intermediate components that do not actually need the data.

02

Context Provider

Wraps component trees with a Provider to supply shared data to all child components.

03

useContext Hook

Allows any nested component to directly read and subscribe to the context value.

04

Global State

Ideal for shared app data like themes, user authentication status, or preferred language.
